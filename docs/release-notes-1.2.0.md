## 1.2.0 — 2026-09-14

这一版**全部是界面的正确性**：浅色主题下读不清的字、写死的深色、以及"只在启动时生效一次"的外观设置。
顺带把这类 bug 的来源收敛成一条 —— **主题令牌里写死的深色值**（带着 `!important` 压在主题之上）
—— 并给 e2e 加了一条**对比度断言**：它自己第一次运行就抓到两个真缺陷。

### Fixed

- **浅色主题读不清。** 聊天里的标题/粗体是写死的 `#f2f4f8`，在白底上是 **1.1:1** ——
  这就是"标题看不清"反复出现的原因；行内代码同理。现在两者都跟随主题令牌。
- **代码块黑底。** `pre` 曾写死 `#12151a !important`，浅色主题下是一块黑板；现在走 `--pi-code-bg`。
- **链接压不住。** 链接用的是**原始强调色**（实测 3.20:1）；现在浅色主题取"变暗到可读"的那个色调，
  实测 **6.54:1**。
- **淡色文字。** `今天 / 刚刚` 一类用 2.89:1 的灰；改为 `#5f6878`。深色主题下顶栏
  "made by HEAOZIE" 只有 2.2:1，现在跟随令牌。
- **选中文字可读。** 选择背景原本是高饱和强调色压在白字上；现在用 `color-mix` 的低比例强调色 +
  主题正文色。
- **双层输入框 / 双层焦点环。** `.composer` 与 `.composer-box` 各画一层边框；现在只留一层。
- **实时改主题、改强调色现在真的生效。** 启动之后的所有外观变更都落在一个被忽略的文档上：注入的
  令牌 `<style>` 从来没有被替换过，而内置聊天 UI 也不监听主题消息。现在由壳层就地替换该元素。
- **强调色"第二次改不生效"。** 设置窗原来用"关掉再重开"来套用外观改动，第二次改动会被丢掉；
  现在**原地刷新**（e2e：FAIL 2 → 0）。
- **顶栏会话名。** 两条加载路径都会把标题卡在"加载中"；现在切换落定后镜像会话名。
- **整段回复不再是点击区。** 点正文会折叠、选字会被误触；现在正文不可点、光标为文字。
- **窗口图标。** 主窗、设置窗、聊天窗统一为 Pi 标记。

### Added

- **对比度断言（e2e）。** 在浅色与深色下遍历页面上的所有元素，低于 4.5:1 即失败；大字/粗体与
  强调色按钮按 WCAG 1.4.11 取 3:1。它第一次运行就找到了 `.pi-tb-brand` 的 2.2:1 与另一处真缺陷。
- **补齐 26 个 `--vscode-*` 变量桥接。** 内置的聊天 UI 会读这些变量，缺一个就静默回退成默认值 —
  症状是"有些地方的颜色说不清为什么不对"。

### Changed

- **回答默认展开。** 长回答、长提问都默认展开，按钮变成"收起"。
- 统计摘要（轮数 / 时长 / +增 -删）改用 `textContent` 构建（该函数本来就只产生纯文本）。

### Known issues

- **字号设置不会改变聊天文字大小。** 根因已实测定位：内置聊天 UI 自己的样式表远在注入点之后，
  而 **CSS 变量声明无法用 `!important` 压制**（颜色能修好，正是因为有这个手段）。两条修法都已尝试
  并回退。实测数据与**下一步该做的测量**写在 [docs/KNOWN-ISSUES.md](../docs/KNOWN-ISSUES.md)。

## 安装

需要 **Windows 10 / 11（x64）**、**Node.js ≥ 22**，以及 `pi` CLI：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

再准备至少一个 provider 的凭据（写在 `~/.pi/agent/auth.json`，或让应用带你在内置终端里登录）。
安装程序可自选目录，会自动创建桌面与开始菜单快捷方式；便携版免安装直接运行，但**不支持自更新**。

## 注意

- **本版仍未签名**：首次运行 Windows SmartScreen 会提示"已保护你的电脑"，
  点 **更多信息 → 仍要运行**；或先比对下方 SHA256。签名申请走
  [SignPath Foundation](https://signpath.org/foundation)，仓库侧已就绪。
- 已安装的 1.1.x 会在启动约 20 秒后自动检查并下载本版；**便携版需手动换包**。
- 发布前的门禁：`npm test` **127/127（0 跳过）**、`npm run verify`（真窗口）、
  `npm run e2e`、`npm run e2e:isolated`、`npm run smoke`、`npm run check:package`
  （打包产物含全部 13 条运行时依赖）。
