## 1.2.2 — 2026-09-15

### Fixed

- **拖出来的子窗口不会载入会话。** 1.2.1 把子窗口换成「只有标题栏 + 对话」的精简外壳，跳过面板脚本之后
  会话就不再出现（窗口照开、标题正确、里面是空的）。已排除布局因素：三张面板样式表里影响全局或聊天区的
  选择器命中 **0** 条，所以问题在某条被跳过的脚本做了什么，但在**测出是哪一条之前**，子窗口先用回完整外壳
  （已知能载入会话）。精简外壳仍留在代码里（`buildChatHtml(..., { minimal: true })`），并由契约测试覆盖，
  定位后再接上。
- **e2e 新增断言「子窗口真的显示出了对话」。** 原来的检查只验窗口存在、标题与位置，所以"窗口是空的"
  这个缺陷能整片逃过去 —— 这条断言就是这次修复的证明。

## 安装

需要 **Windows 10 / 11（x64）**、**Node.js ≥ 22**，以及 `pi` CLI：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

再准备至少一个 provider 的凭据（写在 `~/.pi/agent/auth.json`，或让应用带你在内置终端里登录）。
安装程序可自选目录，会自动创建桌面与开始菜单快捷方式；便携版免安装直接运行，但**不支持自更新**。

## 注意

- **本版仍未签名**：首次运行 Windows SmartScreen 会提示"已保护你的电脑"，
  点 **更多信息 → 仍要运行**；或先比对下方 SHA256。
- 已安装的 1.2.x 会在启动约 20 秒后自动检查并下载本版；**便携版需手动换包**。
- 1.2.1 的子窗口缺陷只影响**拖出来的独立窗口**；主窗口一直正常。
