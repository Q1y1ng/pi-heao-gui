## 1.2.3 — 2026-09-18

### Fixed

- **拖出来的子窗口空白：标题正确，里面没有对话。** 根因是 `preload` 的 `onMessage` 是**单监听器**：shim 持有它，
  把宿主的每条消息转发成 `window` 的 `message` 事件（内置聊天界面听的正是它），而精简外壳自己的标题脚本
  **在同一通道上又注册了一次**，把 shim 顶掉 —— 于是界面一条消息也收不到，标题却照常更新（顶替者本人正是读
  `sessionInfo` 的那一个），而且**全程不报错**。标题脚本改为监听转发出来的事件，与其他脚本和界面本身一致。
  本版起**子窗口默认使用精简外壳**（拖拽标题栏 + 对话）；`PI_MINIMAL_CHILD=0` 可切回完整外壳做对照。

- **字号设置现在运行中改也生效 —— 1.2.0 起记录的那条终于修到底。** 内置聊天 UI 启动时会把 `--chat-fs` **内联**
  写在 `<html>` 上（取自 `window.__PI_FONTSIZE__`），而**内联样式赢过所有样式表**：于是"赢下层叠的那一份"就是
  加载时写下、此后再不改写的那一份，我们的 token 再准也白搭。应用侧的 shim 现在把它重新指向主控
  （`--chat-fs: var(--pi-fs-md, 13px)`，引用会自己跟随）。实测：设为 16 时真消息节点 **16px**、设为 22 时
  **22px**，**运行中改当场跟随**；e2e 已断言这一条（此前只能断言"加载时生效"）。

### Changed

- **子窗口"偶尔空白"的竞态**：宿主的首次状态推送可能落在界面挂载之前（实测 6→10 秒之间才渲染；带诊断负载时
  6 秒仍空）。现在在 600ms / 1.8s / 5s / 12s 各重播一次状态（幂等、会话销毁即放弃），子窗口内容稳定出现。
- **新增默认关闭的诊断开关** `PI_DEBUG_WINDOW=1`：打印子窗口的 console、preload 错误、加载失败、DOM 指纹与
  时间序列。它们不影响正常使用，只为下一次"要看不要猜"的排查。
- **变更面板可以直接切换工作副本（git worktree）**：下拉列出仓库的所有工作副本（含分离 HEAD 的），选中即切换
  工作区，文件、终端、新会话与会话绑定一起跟随。解析器是纯函数，另有 9 条单测，并用真仓库的 porcelain 输出取证。

## 安装

需要 **Windows 10 / 11（x64）**、**Node.js ≥ 22**，以及 `pi` CLI：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

再准备至少一个 provider 的凭据（写在 `~/.pi/agent/auth.json`，或让应用带你在内置终端里登录）。
安装程序可自选目录，会自动创建桌面与开始菜单快捷方式；便携版免安装直接运行，但**不支持自更新**。

## 注意

- **本版仍未签名**：首次运行 Windows SmartScreen 会提示"已保护你的电脑"，
  点 **更多信息 → 仍要运行**；或先比对下方 SHA256。
- 已安装的 1.2.x 会在启动约 20 秒后自动检查并下载本版；**便携版需手动换包**。
