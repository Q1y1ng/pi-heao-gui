## 1.2.4 — 2026-09-19

### Added

- **图片与音频预览。** 文件面板里点开 PNG / JPG / GIF / WebP / BMP / ICO / AVIF / SVG 会直接显示图片
  （按比例缩放适配、不拉伸）；点开 MP3 / WAV / OGG / M4A / AAC / FLAC / OPUS 会显示带控件的播放器。
  上限 10 MB，走 `data:` URL，与背景图同一套做法 —— 页面的 CSP 本来就对 `img-src` / `media-src` 放行
  `data:`，所以**没有放宽任何安全策略**。其余文件仍进原来的编辑器：判定只看扩展名，`logo.png.bak`
  这种备份仍是文本。
- 顺带补上一处安全细节：媒体文件打开时 **`Ctrl+S` 不会把（空的）编辑器内容写回去** —— 键盘快捷键是全局的，
  它并不知道面板在显示什么。e2e 会校验 PNG 的字节在按下 `Ctrl+S` 之后**逐字节不变**。

### Fixed

- **git 面板上的「刷新」现在会刷新工作副本下拉。** 用 `git worktree add` 在应用运行期间新建的工作副本，
  此前要等到整页重新加载才会出现在下拉里 —— 对一个写着“刷新”的按钮来说很奇怪。
- **编辑器与文件树的配色现在跟主题走。** CodeMirror 自带的配色是给白底设计的，在两套主题上都不可读
  （无障碍门禁量到：浅色下行号 **2.85:1**、暗色下字符串 **2.59:1**）。文件树的箭头/圆点列叠了 0.7 的透明度，
  于是 5.59:1 的颜色被合成为 **2.99:1**；错误横幅的红字压在自己的 14% 红底上只有 **4.0:1**。
  前者改用与其它界面相同的 token（调色板里没有可读色相可用时，层次改用字重表达），
  错误横幅保留红色底、文字改用正文色 —— 仍是一眼能认出的错误。两套主题现在都过 4.5:1 门禁。

## 安装

需要 **Windows 10 / 11（x64）**、**Node.js ≥ 22**，以及 `pi` CLI：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

再准备至少一个 provider 的凭据（写在 `~/.pi/agent/auth.json`，或让应用带你在内置终端里登录）。
安装程序可自选目录，会自动创建桌面与开始菜单快捷方式；便携版免安装直接运行，但**不支持自更新**。

## 注意

- **本版仍未签名**：首次运行 Windows SmartScreen 会提示“已保护你的电脑”，
  点 **更多信息 → 仍要运行**；或先比对下方 SHA256。
- 已安装的 1.2.x 会在启动约 20 秒后自动检查并下载本版；**便携版需手动换包**。
